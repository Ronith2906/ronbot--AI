## 🚀 Quick Start

### Prerequisites
- Flutter SDK 3.0+
- Dart 3.0+
- Chrome browser (for web development)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/ronbot-ai.git
   cd ronbot-ai
   ```

2. **Install dependencies**
   ```bash
   flutter pub get
   ```

3. **Configure API keys** (Optional for demo)
   ```dart
   // lib/config.dart
   static const String openaiApiKey = 'your-openai-key';
   static const String elevenLabsApiKey = 'your-elevenlabs-key';
   static const String newsApiKey = 'your-news-api-key';
   ```

4. **Run the application**
   ```bash
   flutter run -d chrome
   ```

## 🔧 Configuration

### API Keys Setup
1. **OpenAI**: Get API key from [OpenAI Platform](https://platform.openai.com/)
2. **ElevenLabs**: Sign up at [ElevenLabs](https://elevenlabs.io/)
3. **News API**: Register at [NewsAPI.org](https://newsapi.org/)

### Environment Variables
```bash
OPENAI_API_KEY=your_openai_key
ELEVENLABS_API_KEY=your_elevenlabs_key
NEWS_API_KEY=your_news_api_key
```
