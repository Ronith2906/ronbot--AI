# RonBot AI

> Advanced AI assistant with voice synthesis and real-time news — built with Flutter.

**Author:** Sylvester Ronith Reagan  
**Status:** Early development / planning

---

## Overview

RonBot AI is a cross-platform mobile assistant that combines conversational AI, text-to-speech voice synthesis, and real-time news aggregation. The app is designed to deliver a natural, voice-first experience for getting answers, summaries, and updates on the go.

---

## Planned Features

| Feature | Description |
|---|---|
| **Conversational AI** | Chat interface powered by LLM APIs (OpenAI / Anthropic) |
| **Voice synthesis** | Text-to-speech responses for hands-free interaction |
| **Real-time news** | Curated news feed with AI-generated summaries |
| **Cross-platform** | iOS and Android from a single Flutter codebase |
| **Offline support** | Cache recent conversations and news for offline access |

---

## Tech Stack (Planned)

| Component | Technology |
|---|---|
| Framework | Flutter (Dart) |
| AI / LLM | OpenAI or Anthropic API |
| Voice | Flutter TTS / speech-to-text plugins |
| News | News API or RSS aggregation |
| State management | Riverpod or Provider |
